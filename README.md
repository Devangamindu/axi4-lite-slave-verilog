# AXI4-Lite Slave in Verilog

## Overview

Designed and verified an AXI4-Lite Slave interface in Verilog HDL for memory-mapped register access.

## Features

- AXI4-Lite write transaction handling
- AXI4-Lite read transaction handling
- Address decoding
- Register read/write logic
- Valid/Ready handshaking

## Concepts

- AMBA AXI4-Lite protocol
- Ready/Valid handshake
- Memory-mapped interfaces
- FSM-based control
- RTL verification

## Verification

Verified AXI4-Lite read and write transactions using Xilinx Vivado simulation and waveform analysis.

## Tools

- Verilog HDL
- Xilinx Vivado
